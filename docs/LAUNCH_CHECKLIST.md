# Ручные шаги перед запуском

Всё, что делается в коде, уже в `main`. Ниже — только то, что требует твоих аккаунтов, денег или решений.
Порядок важен: сверху вниз.

## 1. Название и домен
- [ ] Выбрать название (Plato занят; варианты: Misely, Rotaly, Miseplan, Brigada, Passly…).
- [ ] Проверить товарный знак в классе 42/35 (USPTO — США, EUIPO — ЕС) и купить домен (`.com`, либо `get<name>.com` / `<name>.app`).
- [ ] Написать мне название — я переименую приложение, письма, лого (концепция «7 дней по кругу») и баннер.

## 2. Railway: переменные сервиса **api**
| Переменная | Значение |
| --- | --- |
| `APP_ENV` | `production` |
| `SECRET_KEY` | длинная случайная строка (`python -c "import secrets; print(secrets.token_urlsafe(48))"`) |
| `FRONTEND_URL` | адрес сайта, например `https://<домен>` |
| `CORS_ORIGINS` | тот же адрес сайта |
| `AUTH_SESSION_SECURE_COOKIE` | `true` |
| `PLATFORM_ADMIN_EMAILS` | твоя почта (через запятую, если несколько) — открывает «Платформу» |
| `DEV_LOGIN_SECRET`, `DEV_LOGIN_EMAIL` | тестовый вход; перед публичным запуском смени секрет на новый |
| `RESEND_API_KEY`, `RESEND_FROM_EMAIL` | см. п. 4 |
| `PUSH_CONTACT_EMAIL` | почта поддержки на новом домене |
| `SENTRY_DSN` | необязательно, для отчётов об ошибках (sentry.io, бесплатный план) |

Сервис **web**: `VITE_API_URL` (адрес API); для рекламы — `VITE_META_PIXEL_ID` и/или `VITE_GA_ID` (баннер согласия появится сам).

Ключи для push генерируются автоматически и хранятся в базе — ничего задавать не нужно.

## 3. Stripe (боевой режим)
- [ ] Создать 2 продукта (Starter, Pro) и 8 цен, **за точку** (quantity = число точек):

  | | USD / мес | USD / год | PLN / мес | PLN / год |
  | --- | --- | --- | --- | --- |
  | Starter | 26 | 260 | 99 | 990 |
  | Pro | 58 | 580 | 219 | 2190 |

- [ ] ID цен вписать в `STRIPE_PRICE_{STARTER,PRO}_{USD,PLN}_{MONTHLY,ANNUAL}`, ключ — в `STRIPE_SECRET_KEY`.
- [ ] Webhook: `https://<api>/billing/webhooks/stripe`, события `checkout.session.completed`, `customer.subscription.created`, `customer.subscription.updated`, `customer.subscription.deleted`, `invoice.payment_failed`; секрет — в `STRIPE_WEBHOOK_SECRET`.
- [ ] Включить Customer Portal (отмена, смена карты).
- [ ] Решить с налогами: Stripe Tax для sales tax в США.
- [ ] Купить Starter своей картой, проверить, что план сменился, потом сделать возврат.

## 4. Почта
- [ ] Добавить домен в Resend, прописать DNS (SPF, DKIM, DMARC).
- [ ] `RESEND_FROM_EMAIL` = например `hello@<домен>`.
- [ ] Проверить: регистрация (код приходит не в спам), приглашение сотрудника.

## 5. Юридическое
- [ ] Зарегистрировать компанию (LLC в США или sp. z o.o. в Польше).
- [ ] Прислать мне название компании и адрес — впишу в Terms / Privacy (EN и PL).
- [ ] Показать тексты юристу (особенно ответственность, возвраты, трудовое право).
- [ ] Почта поддержки на новом домене.
